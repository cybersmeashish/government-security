# Reference provenance and applicability

`primary-sources.json` records source URLs, versions, retrieval results and hashes. Raw standards/statutory downloads are not republished. An HTTP response is not assumed to be the requested authoritative document: the 2025 USC response was an HTML error page and is explicitly unusable.

The retrieved SP 800-53 official OSCAL catalog identifies version **5.2.0**, last modified **2026-10-22**. Selected control titles in the mapping come from that exact snapshot. The separate SP 800-53B PDF is the October 2020 baseline publication.

Current statutory/agency applicability remains distinct from archived text. The verified 2024 USC and 2014 FISMA enactment support historical context. Later amendments and the current agency/system obligations require separate verification.

`upstream-lock.json` pins the shared research commit and 52 selected source inputs. Runtime code is loaded only after those bytes match. Shared cryptography and admission are not presented as independently invented government implementations.
