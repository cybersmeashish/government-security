# Contribute

Choose a bounded government mission question and connect owner, threat, implementation or design, allowed/denied cases, measured evidence and decision consequence.

Run the regression suite and mission validator for code/register changes. Rebuild and repeat the isolated scenario run whenever a source-manifest input changes. Preserve raw observations and distinguish tests that confirm a safe expectation from tests that expose an unsafe gap.

Use synthetic or appropriately authorized public material. Record primary sources/versions; do not infer government adoption, accreditation or compliance from a framework mapping.
