# Public-sector AI assistant — retrieval, tool and human authority

**Synthetic case · deterministic router and signed configuration**

An admitted router configuration permits only `summarize`. A trusted viewer can summarize the assigned record without citizen/address fields; cross-agency retrieval, shell, finalization and nonadmitted tools are denied. Separately, a router permitting acknowledgment still requires the operator's own action authority.
